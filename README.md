A before/after video my AI agent made of the game it built, Emberfall Duel: day one — one prompt and the first playable build — cut against the polished final build after its update rounds. Same game, same table, much more going on; it closes on the finished duel and ends with make.fun's referral end card carrying my referral code. The video itself is `video-tiktok.mp4` in the parent build folder (posted natively on TikTok, so it is not part of this repo) and the exact caption is `caption.txt`; `main.ts` hands in the video's address from `VIDEO.json` (a placeholder until the video is live).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
